# WiiGame Portal v13 — Responsive Desktop + Mobile

## Desktop (>=850px)
- Layout dashboard rộng, sidebar trái với 4 mục chính + Giải đấu, Phần thưởng, Gói chơi.
- Header phía trên, nội dung nhiều cột, game grid 3–5 cột theo độ rộng.
- Banner, game cards, bộ lọc, gói chơi, tài khoản, đăng nhập và popup được tối ưu desktop.
- Trang dài cuộn trong vùng nội dung; thanh danh mục có thể kéo chuột, lăn chuột.
- Đăng nhập G08 hiển thị dưới dạng form card ở giữa thay vì khung điện thoại.
- Desktop và mobile dùng chung dữ liệu và cùng chức năng.

## Mobile (<850px)
- Giữ giao diện v12, footer 4 tab, vuốt danh mục, LocalStorage và các luồng.
- OTP demo: 123456. Gói chơi và điểm là dữ liệu mô phỏng.
